# Contributing

Thank you for your interest in contributing to the **OpenClaw AI Meeting Assistant** project.

Contributions of all kinds are welcome, including bug fixes, documentation improvements, feature suggestions, and code enhancements.

---

# How to Contribute

## 1. Fork the Repository

Create your own copy of the repository by clicking the **Fork** button on GitHub.

---

## 2. Clone Your Fork

```bash
git clone https://github.com/your-username/OpenClaw-GIAIC-Assignment.git
```

---

## 3. Create a New Branch

Use a descriptive branch name.

```bash
git checkout -b feature/your-feature-name
```

Examples:

- feature/google-calendar
- feature/slack-integration
- fix/trello-api
- docs/update-readme

---

## 4. Make Your Changes

Please follow these guidelines:

- Write clean and readable code.
- Keep commits focused on a single change.
- Update documentation if necessary.
- Test your changes before submitting.

---

## 5. Commit Your Changes

Use meaningful commit messages.

Example:

```bash
git commit -m "Add Trello card automation"
```

---

## 6. Push Your Branch

```bash
git push origin feature/your-feature-name
```

---

## 7. Open a Pull Request

Create a Pull Request describing:

- What was changed
- Why the change was made
- Screenshots (if applicable)

---

# Coding Standards

Please follow these best practices:

- Keep functions small and readable.
- Use descriptive variable names.
- Remove unused code.
- Comment complex logic when necessary.
- Avoid committing sensitive information.

---

# Documentation

If your contribution changes functionality, please update the relevant documentation, including:

- README.md
- CHANGELOG.md
- Setup Guide
- Milestone Documentation

---

# Bug Reports

When reporting a bug, include:

- Operating System
- OpenClaw Version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Error messages
- Screenshots (if available)

---

# Feature Requests

Feature requests should include:

- Problem statement
- Proposed solution
- Benefits
- Possible implementation approach

---

# Security

Please do **not** commit:

- API Keys
- Access Tokens
- Discord Bot Tokens
- OpenRouter Keys
- Trello Tokens
- Passwords
- Personal Credentials

Use environment variables or local configuration files instead.

---

# Code of Conduct

Please be respectful and professional.

We welcome contributors from all backgrounds and experience levels.

Be constructive when giving feedback and reviewing code.

---

# Project Goals

The primary goals of this project are:

- Learn OpenClaw
- Automate meeting workflows
- Improve AI productivity
- Integrate external services
- Demonstrate practical AI agent development
