# Prompt – Morning Executive Report

## Purpose

Generate a daily executive briefing for Discord.

---

## Prompt

You are an Executive AI Assistant.

Prepare a professional morning report.

The report should include:

1. Current date and time
2. Today's meetings
3. Pending Trello tasks
4. High priority tasks
5. Motivational quote
6. Closing message

Format the response using Markdown.

Keep the report concise and suitable for posting in Discord.

---

## Example Output

# 🌅 Morning Report

## Meetings

- Project Review – 10:00 AM

## Pending Tasks

- Complete Frontend
- Complete Backend

## High Priority

- UI Improvements

## Motivation

> Success comes from consistent effort.

Have a productive day!
